کلید Gemini

اپ برای تبدیل صدا به متن و ترجمه از Gemini گوگل استفاده می‌کند. یک کلید رایگان لازم است:

  1. برو به aistudio.google.com/apikey و با حساب گوگلت وارد شو.
  2. دکمه‌ی ساخت کلید (Create API key) را بزن. اسم دکمه‌ها ممکن است کمی فرق کند.
  3. کلید را کپی کن و همین‌جا بچسبان.

مدل‌های lite سریع‌ترند و سهمیه‌ی روزانه‌ی بیشتری دارند. مدل‌های بدون lite معمولاً دقیق‌ترند ولی سهمیه‌ی رایگانشان کمتر است.

کلید فقط روی همین گوشی ذخیره می‌شود. آن را به کسی نده و جایی مثل GitHub نگذار. صدای فایل برای پردازش به سرور گوگل فرستاده می‌شود.
